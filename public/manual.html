1. ภาพรวมระบบ

ระบบ Community Driven ใช้สำหรับบันทึกและติดตามข้อมูลโครงการชุมชนสุขภาวะ ครอบคลุม 3 โครงการหลัก ได้แก่

โครงการเป้าหมาย KPI (ปีที่ 3)
เลิกเหล้า≥ 10% ของผู้เข้าร่วม
เลิกบุหรี่≥ 15% ของผู้เข้าร่วม
ดื่มไม่ขับ≥ 10% ของผู้เข้าร่วม

ข้อมูลจะถูกติดตาม 3 ปี ต่อเนื่อง นับจากปีฐาน พ.ศ. 2569

2. การเข้าสู่ระบบ

2.1 เข้าสู่ระบบ

  1. เปิดเบราว์เซอร์ ไปที่ URL ของระบบ
  2. กรอก อีเมล และ รหัสผ่าน
  3. กด เข้าสู่ระบบ

> หมายเหตุ: ต้องมี Role เป็น ADMIN จึงจะเข้าใช้ Dashboard ได้ หากเป็น MEMBER จะไม่สามารถเข้าหน้า Dashboard ได้

2.2 สมัครสมาชิกใหม่

  1. คลิก สมัครสมาชิก ในหน้า Login
  2. กรอกข้อมูล: ชื่อ, นามสกุล, อีเมล, รหัสผ่าน, จังหวัด/อำเภอ/เขต
  3. กด สมัครสมาชิก
  4. รอ Admin อนุมัติ Role เป็น ADMIN ก่อนใช้งาน

2.3 ลืมรหัสผ่าน

  1. คลิก ลืมรหัสผ่าน ในหน้า Login
  2. กรอกอีเมล → กด ส่งลิงก์รีเซ็ต
  3. เช็คอีเมลและคลิกลิงก์ภายใน 1 ชั่วโมง
  4. ตั้งรหัสผ่านใหม่

3. Dashboard — ภาพรวมข้อมูลทั้งหมด

หน้า Dashboard แสดงสรุปข้อมูลทั้งหมดในระบบ แบ่งเป็น:

การ์ด KPI หลัก

  • จำนวนหมู่บ้านในระบบ
  • จำนวนสมาชิกทั้งหมด
  • ประชากรและอัตราคัดกรอง (%)
  • หมู่บ้านที่มีผลคัดกรอง

ความคืบหน้าแยกตามปี (Progress Funnel)

แสดงกราฟความก้าวหน้าของแต่ละโครงการ (เหล้า / บุหรี่ / ดื่มไม่ขับ) แยกปีที่ 1, 2, 3 พร้อมแสดง ยอดผู้เสียชีวิต แยกต่างหาก

กราฟอื่น ๆ

  • ความเสี่ยงแอลกอฮอล์
  • ผลลัพธ์รายบุคคล
  • การมีส่วนร่วมขององค์กร
  • ตารางความพร้อมของหมู่บ้าน
  • สรุปรายเขต

4. จัดการหมู่บ้าน

4.1 ดูรายการหมู่บ้าน

เมนู → หมู่บ้าน

รายการแสดงหมู่บ้านทั้งหมดในระบบ สามารถ:

  • ค้นหาด้วยชื่อหมู่บ้าน / ตำบล / อำเภอ / จังหวัด
  • กดการ์ดหมู่บ้านเพื่อดูรายละเอียด

4.2 เพิ่มหมู่บ้านใหม่

  1. กด + เพิ่มหมู่บ้าน
  2. กรอกข้อมูล:
ฟิลด์คำอธิบายจำเป็น
ชื่อหมู่บ้านชื่อบ้าน เช่น "บ้านหยอด"✅
หมู่ที่หมายเลขหมู่✅
ตำบล/อำเภอ/จังหวัดพิมพ์ค้นหาแล้วเลือกจากรายการ✅
ประชากรตามทะเบียนบ้านจำนวนคน—
ประชากรอาศัยอยู่จริงจำนวนคน (ใช้คำนวณอัตราคัดกรอง)—
จำนวนครัวเรือนจำนวนหลังคาเรือน—
ชื่อผู้ประสานงานชื่อ-นามสกุล✅
เบอร์โทรศัพท์เบอร์ติดต่อ—
  1. กด บันทึก → ระบบพาไปหน้ารายละเอียดหมู่บ้านอัตโนมัติ

4.3 แก้ไขข้อมูลหมู่บ้าน

ในหน้ารายละเอียดหมู่บ้าน → กดไอคอน ดินสอ (Edit) ด้านบน

4.4 ลบหมู่บ้าน

ในหน้ารายละเอียดหมู่บ้าน → กดปุ่ม ลบหมู่บ้าน (สีแดง) → ยืนยัน

> ⚠️ การลบหมู่บ้านจะลบข้อมูลทั้งหมดที่เกี่ยวข้องถาวร ไม่สามารถกู้คืนได้

5. ข้อมูลหมู่บ้าน

เมื่อคลิกเข้าหน้ารายละเอียดหมู่บ้าน จะพบ 5 ส่วนหลัก บันทึกอัตโนมัติ (Autosave) ทุกส่วน

5.1 ข้อมูลพื้นฐานชุมชน

บันทึกว่าชุมชนมีเอกสาร/ข้อมูลใดบ้าง

วิธีใช้:

  1. ติ๊ก ☑ รายการที่ชุมชนมี
  2. เมื่อติ๊กแล้ว ระบบจะแสดงปุ่ม แนบไฟล์ (PDF, Word)
  3. คลิกปุ่มแนบไฟล์ → เลือกไฟล์จากเครื่อง (ไม่เกิน 10 MB)
  4. ไฟล์จะถูกอัปโหลดและแสดงชื่อไฟล์พร้อมลิงก์เปิด

รายการข้อมูล:

  • ข้อมูลปฏิทินชุมชน
  • ข้อมูลความเจ็บป่วยต่อสถานที่เสี่ยง
  • ข้อมูลนโยบายการมีส่วนร่วม
  • ข้อมูลนโยบายพัฒนาศักยภาพการทำงาน
  • ข้อมูลประวัติชุมชน

> สังเกต Header:

> 🟠 "ยังไม่มีไฟล์ N รายการ" = ติ๊กแล้วแต่ยังไม่แนบไฟล์

> 🟢 "บันทึกแล้ว" = ครบถ้วนสมบูรณ์

5.2 ผลการคัดกรองประชากร

บันทึกจำนวนผู้ถูกคัดกรองแยกตามกลุ่มความเสี่ยง

วิธีใช้:

  1. กรอกตัวเลขในแต่ละช่อง
  2. กด Tab หรือคลิกออกจากช่องเพื่อบันทึก

ข้อมูลที่กรอก:

กลุ่มฟิลด์
รวมจำนวนคนคัดกรองทั้งหมด
แอลกอฮอล์เสี่ยงต่ำ / เสี่ยงสูง / อันตราย / ติดสุรา
บุหรี่สูบบุหรี่
การขับขี่ดื่มแล้วขับ / ดื่มไม่ขับ

ระบบจะคำนวณ อัตราคัดกรอง (%) จากประชากรจริงให้อัตโนมัติ

5.3 สิ่งแวดล้อม

บันทึกองค์ประกอบสิ่งแวดล้อมในชุมชน ติ๊กเพื่อระบุว่ามีหรือไม่ สามารถเพิ่มรายละเอียดได้เมื่อติ๊ก

งานศพปลอดเหล้า

  • ติ๊ก มี → แสดง sub-options:
- มีนโยบาย — ติ๊กแล้วแนบไฟล์นโยบาย

- มีกติกาชุมชน — ติ๊กแล้วแนบไฟล์กติกา

งานประเพณีปลอดเหล้า

  • ติ๊ก มี → แสดง sub-options:
- งานประเพณี — ติ๊กแล้ว กด + เพิ่มชื่องาน เพิ่มชื่องานได้หลายรายการ

- สถานที่ห้ามดื่มห้ามขาย — ติ๊กแล้ว กด + เพิ่มสถานที่

ร้านค้า

  • ติ๊ก มี → แสดง sub-options:
- ไม่ขายเหล้าเลย — เพิ่มชื่อร้านได้

- ร้านขายเข้าร่วมตามกฎหมาย — เพิ่มชื่อร้านได้

สถานที่ห้ามดื่มห้ามขาย

  • ติ๊ก มี → แสดง sub-option:
- สถานที่ห้ามดื่มห้ามขาย — กด + เพิ่มสถานที่ เพิ่มชื่อสถานที่ได้หลายรายการ

> สังเกต Header:

> 🟠 "ยังไม่มีไฟล์ N รายการ" = ติ๊กนโยบาย/กติกาแล้วแต่ยังไม่แนบไฟล์

> 🟢 "บันทึกแล้ว" = ครบถ้วน

5.4 การมีส่วนร่วมของชุมชน

บันทึกหน่วยงานในชุมชนที่มีส่วนร่วมในโครงการ

วิธีใช้:

  1. ติ๊ก ☑ หน่วยงานที่มีส่วนร่วม
  2. กด + เพิ่มชื่อ... เพื่อเพิ่มชื่อบุคคล/หน่วยงาน (เพิ่มได้หลายคน)
  3. กดไอคอน × เพื่อลบชื่อ

หน่วยงาน:

  • สถานศึกษา
  • วัด/ศาสนสถาน
  • ท้องถิ่น (อบต./เทศบาล)
  • ท้องที่ (กำนัน/ผู้ใหญ่บ้าน)
  • รพ.สต.
  • กลุ่มองค์กร

5.5 ผลการประเมิน 3 ปี

แสดงสรุปผลการประเมินสมาชิกในหมู่บ้าน แยก 3 กลุ่ม (เหล้า / บุหรี่ / ดื่มไม่ขับ)

ข้อมูลที่แสดง:

  • จำนวนสมาชิกต่อกลุ่ม
  • อัตราการประเมินแล้ว (X/Y คน)
  • Badge เสียชีวิต (ถ้ามี)
  • Progress bar สีตามผล
  • สรุป KPI — ✓ บรรลุ / ต่ำกว่าเป้า
  • รายชื่อสมาชิกที่ยังไม่ประเมินปีที่ 2 (สีเหลือง)
  • รายชื่อสมาชิกที่ยังไม่ประเมินปีที่ 3 (สีส้ม)

สีของ Progress Bar:

สีความหมาย
🟢 เขียวเลิกได้แล้ว / บรรลุเป้าหมาย
🔵 น้ำเงินลดพฤติกรรมได้
🔷 ฟ้าลดได้บางส่วน
🟠 ส้มยังคงพฤติกรรมเดิม
🔴 แดงไม่บรรลุเป้าหมาย / ออกจากโครงการ
⚫ เทาเข้มเสียชีวิต (ไม่นับใน KPI)
⚪ เทาอ่อนยังไม่ประเมิน

กดปุ่ม "เกณฑ์" ด้านบนขวาเพื่อดูรายละเอียดเกณฑ์การประเมินและสูตร KPI

6. จัดการสมาชิก

6.1 เพิ่มสมาชิกใหม่

Navigate: หน้าหมู่บ้าน → กด + เพิ่มสมาชิก

ขั้นตอน:

ข้อมูลพื้นฐาน

ฟิลด์คำอธิบาย
ชื่อ-นามสกุลชื่อจริงของสมาชิก
เพศชาย / หญิง / LGBTQ

กลุ่มเหล้า (ถ้าดื่ม)

  1. ติ๊ก "บุคคลนี้ดื่มเครื่องดื่มแอลกอฮอล์"
  2. เลือก ประเภทการดื่ม: เสี่ยงต่ำ / เสี่ยงสูง / อันตราย / ติดสุรา
  3. เลือก สถานะปีที่ 1 (วัดเจตนา):
- ตั้งใจเลิก
  • - มีแนวโน้มที่จะเลิก
  • อยากลดแต่ยังมีอุปสรรค
  1. เพิ่ม ผลลัพธ์รายปี (ไม่บังคับ) — ติ๊กหัวข้อที่บรรลุผลได้:
- จำนวนเงินประหยัด/เดือน → เลือกช่วงเงิน
  • - ทรัพย์สิน / ครอบครัว / สุขภาพ / งาน / ได้รับการยอมรับ / อื่นๆ → เพิ่มรายละเอียดได้

กลุ่มบุหรี่ (ถ้าสูบ)

  1. ติ๊ก "บุคคลนี้สูบบุหรี่หรือยาสูบ"
  2. เลือก ประเภทการสูบ:
- สูบประจำ → เลือกจำนวนมวน/วัน
  • - นานๆ ครั้ง → ติ๊กโอกาสที่สูบ (เวลาสังสรรค์ / เวลาเครียด)
  1. เลือก สถานะปีที่ 1

กลุ่มดื่มไม่ขับ (ถ้าเคยดื่มแล้วขับ)

  1. ติ๊ก "บุคคลนี้เข้าร่วมโครงการดื่มไม่ขับ"
  2. เลือก ประเภทพฤติกรรมเดิม
  3. เลือก สถานะปีที่ 1

กด บันทึกข้อมูลสมาชิก

> หมายเหตุ: ต้องเลือกอย่างน้อย 1 กลุ่ม จึงจะบันทึกได้

6.2 แก้ไขข้อมูลสมาชิก

Navigate: หน้าหมู่บ้าน → กดชื่อสมาชิก → กด แก้ไข

สามารถแก้ไขได้ทุกฟิลด์รวมถึง:

  • สถานะปีที่ 2 และ 3 (เมื่อถึงเวลาติดตาม)
  • ผลลัพธ์รายปี

การบันทึกสถานะการเสียชีวิต

เมื่อสมาชิกเสียชีวิตระหว่างโครงการ:

  1. เปลี่ยนสถานะ ปีที่ 2 = เสียชีวิต
  2. ระบบจะตั้งปีที่ 3 = เสียชีวิต อัตโนมัติ
  3. หากสมาชิกอยู่หลายกลุ่ม ระบบจะอัปเดตทุกกลุ่มพร้อมกัน
  4. สมาชิกที่เสียชีวิตจะ ไม่ถูกนับในการคำนวณ KPI

6.3 โหมดประเมิน (Evaluate Mode)

Navigate: หน้าหมู่บ้าน → กดปุ่ม "ประเมิน" ด้านบน

โหมดนี้ออกแบบมาเพื่อ กรอกผลติดตามปีที่ 2-3 ได้รวดเร็ว — แสดงสมาชิกทุกคนพร้อมกัน

วิธีใช้:

  1. หน้าจะแสดง progress bar — ประเมินครบแล้ว X/Y คน
  2. แต่ละ card แสดงชื่อสมาชิก + กลุ่มที่เข้าร่วม
  3. เลือก dropdown ปีที่ 2 และ 3 ของแต่ละกลุ่ม
  4. ระบบ บันทึกอัตโนมัติทันที เมื่อเปลี่ยน dropdown
  5. Card ที่ประเมินครบจะแสดงขอบ สีเขียว พร้อมไอคอน ✓

ตัวเลือกสถานะปีที่ 2 (เหล้า/บุหรี่):

  • เลิกได้แล้ว
  • ลดพฤติกรรมได้
  • ยังคงพฤติกรรมเดิม
  • ออกจากโครงการ
  • เสียชีวิต

ตัวเลือกสถานะปีที่ 3 (เหล้า/บุหรี่):

  • เลิกได้แล้ว ✓ นับ KPI
  • ลดพฤติกรรมได้อย่างต่อเนื่อง ✓ นับ KPI
  • ลดได้บางส่วน
  • ไม่บรรลุเป้าหมาย
  • เสียชีวิต (ไม่นับ KPI)

7. รายงานและ Export

Navigate: เมนู → รายงาน

ตัวกรอง

  • จังหวัด / อำเภอ / ตำบล
  • เขต (Zone)

การ Export

กด Export Excel เพื่อดาวน์โหลดไฟล์ .xlsx ประกอบด้วย:

  • ข้อมูลหมู่บ้านทั้งหมด
  • สรุปผลคัดกรอง
  • สถานะสิ่งแวดล้อม
  • การมีส่วนร่วมหน่วยงาน
  • สรุปสมาชิกรายหมู่บ้าน

8. จัดการผู้ใช้งาน

Navigate: เมนู → ผู้ใช้งาน (เฉพาะ Admin)

แสดงรายชื่อผู้ใช้ทั้งหมดในระบบ สามารถ:

  • เปลี่ยน Role ระหว่าง MEMBER ↔ ADMIN ด้วยการกด Toggle
  • ค้นหาผู้ใช้ด้วยชื่อหรืออีเมล

> ADMIN = เข้าใช้งาน Dashboard ได้ทุกส่วน

> MEMBER = เข้าใช้งานได้เฉพาะโปรไฟล์ตัวเอง

9. คำถามที่พบบ่อย

Q: ข้อมูลหายหลังบันทึกหรือเปล่า?

A: ระบบบันทึกอัตโนมัติ (Autosave) ทุกครั้งที่คลิกออกจากช่อง หรือกดติ๊ก ไม่ต้องกดปุ่มบันทึก (ยกเว้นหน้าเพิ่ม/แก้ไขสมาชิกและหมู่บ้านที่มีปุ่มบันทึกแยก)

Q: KPI คำนวณจากอะไร?

A: KPI คำนวณจากผลปีที่ 3 เท่านั้น สูตรคือ จำนวนสำเร็จ ÷ จำนวนที่ประเมินแล้ว × 100 โดยไม่นับผู้เสียชีวิตในตัวหาร

Q: ผู้เสียชีวิตนับ KPI อย่างไร?

A: ผู้เสียชีวิตจะถูกแยกแสดงเป็น badge "เสียชีวิต N คน" และ ไม่นับ ทั้งใน numerator และ denominator ของ KPI

Q: แนบไฟล์อะไรได้บ้าง?

A: รองรับ PDF, Word (.doc, .docx) ขนาดไม่เกิน 10 MB ต่อไฟล์

Q: ลบสมาชิกได้ไหม?

A: ได้ — ในหน้าแก้ไขสมาชิกมีปุ่ม "ลบสมาชิก" สีแดง การลบจะลบข้อมูลทุกกลุ่มของสมาชิกนั้นถาวร

Q: ถ้าสมาชิกอยู่หลายกลุ่ม (เหล้า+บุหรี่+ดื่มไม่ขับ) และเสียชีวิต ต้องกรอกทุกกลุ่มไหม?

A: ไม่ต้อง — กรอกเสียชีวิตที่กลุ่มใดกลุ่มหนึ่ง ระบบจะอัปเดตทุกกลุ่มอัตโนมัติ

Q: Dashboard แสดงข้อมูล real-time ไหม?

A: ใช่ — ข้อมูลใน Dashboard อัปเดตจาก database โดยตรงทุกครั้งที่โหลดหน้า
